Exoplanet Transit Photometry & Habitability Explorer

A computational model evaluating exoplanetary detection limits via transit photometry and radiative equilibrium.

Mathematical Framework

$$\text{Transit Depth } (\delta) = \left(\frac{R_p}{R_*}\right)^2$$
$$\text{Orbital Period } (T) = \sqrt{a^3} \quad \text{(Kepler's 3rd Law, where } a \text{ is in AU, } T \text{ in years)}$$
$$\text{Equilibrium Temp } (T_{eq}) = T_* \sqrt{\frac{R_*}{2a}}$$
